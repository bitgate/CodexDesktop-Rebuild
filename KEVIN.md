# KEVIN.md

## What this is
Fork of Haleclipse/CodexDesktop-Rebuild — Electron rebuild of the Codex desktop app. Downloads upstream app, unpacks asar, applies `scripts/patch-*.js`, repacks. Default branch `master`.

## Active work
- **Fork binary vendoring** (PR #1, branch `feature/fork-codex-binary`): `resolveCodexVendor` in `scripts/build-from-upstream.js` prefers `CODEX_VENDOR_BIN` env or `vendor/codex/<triple>/codex[.exe]` over `@cometix` packages. Ships bitgate/codex's app-server (profile model selector) inside the desktop app.

## Gotchas
- `src/` is gitignored + generated by `scripts/sync-upstream.js` (~550MB download per mac platform; `--skip-win` helps).
- Renderer is one 13MB minified bundle (`webview/assets/app-initial-*.js`); patch scripts do anchored string replacement — verify anchor uniqueness before writing a patch.
- The model picker already renders any non-hidden `model/list` entry — model-selector work belongs in app-server (bitgate/codex), NOT renderer patches. tai() filter only gates hidden-models mode.
- Build replaces bundled `codex` binary (resources/codex[.exe]) — that's the app-server the GUI talks to.
